Interactive What-If Defense Matrix

"What If...?" Technical Defense

คลิกที่คำถามเพื่อดูคำตอบแก้ต่างเชิงเทคนิคอย่างเป็นมืออาชีพ

1. Nginx Ingress Rate Limit: สกัดกั้นที่ขอบเครือข่ายด้วย directive limit_req_zone $binary_remote_addr zone=api:10m rate=30r/s; ตัดคำขอเกินทิ้งทันทีด้วย HTTP 429

2. WebSocket Token Bucket: มี Sliding Window Throttler ใน Redis คอยตรวจสอบอัตราการส่งข้อความของผู้ใช้ (จำกัด 10 msg/s)

3. Async Connection Pooling: กำหนด pool_size=10, max_overflow=20 บน asyncpg ป้องกัน Database Thread Starvation

1. Zero Message Loss (PostgreSQL Write-Ahead Logging): ข้อความแชททุกข้อความผ่าน SQLAlchemy async session และบันทึกลงดิสก์ถาวรผ่าน WAL (Write-Ahead Log) ก่อนที่ระบบจะส่ง ACK ยืนยันกลับไปยัง Client

2. Redis Persistence (AOF & RDB): Redis ถูกเปิดใช้งาน Append-Only File (AOF) ทำให้เมื่อฟื้นตัวสามารถกู้คืน State ของห้องแชทและ Session ที่จำเป็นได้ทันที

3. Automatic Reconnect & Idempotency: WebSocket Client มีระบบ Reconnect Backoff พร้อมส่ง Client-Generated Message ID (temp_id) เพื่อป้องกันการบันทึกข้อความซ้ำซ้อน (Deduplication)

1. Docker Private Bridge Network: พอร์ต 5432 (Postgres) และ 6379 (Redis) ถูก bind กับ 127.0.0.1 เท่านั้นใน docker-compose.yml

2. No Public Port Exposure: มีเพียงพอร์ต 80 และ 443 ของ Nginx Ingress เท่านั้นที่เปิดรับ Traffic จากภายนอก

3. Host VPC Firewall: กฎ Security Group ของ VPS ปิด Inbound Ports 5432 และ 6379 จาก IP สาธารณะทั้งหมด

1. PostgreSQL Independent Storage: ข้อความแชททุกข้อความถูกบันทึกสำเร็จลง PostgreSQL ก่อนเสมอ จึงไม่สูญหายแม้แต่วินาทีเดียว

2. Graceful Fallback: การดึงประวัติแชทและโปรไฟล์ผู้ใช้จะ fallback จาก Redis Cache ไปดึงจาก Database โดยตรงแบบอัตโนมัติ

3. In-Memory Local Broadcast: เมื่อ Redis Pub/Sub ดับ แต่ละ Worker Node ยังสามารถส่งข้อความให้ Client ที่ต่ออยู่กับ Worker เดียวกันได้โดยไม่ Crash

🎯 คำถามที่เตรียมไว้ใช้ยิงถามทีมอื่น (Challenger Questions)

คำถาม: "ถ้าระบบของคุณมีผู้ใช้งานพร้อมกัน 5,000 คนในห้องแชทเดียวกัน แล้วมีคนส่งรูปภาพขนาดใหญ่ 10MB พร้อมกัน 50 คน เครื่อง Server ของคุณจะเกิด Out of Memory (OOM) ไหม? และมีกลไกจำกัด Request Body Size หรือย้ายการอัปโหลดไปที่ Object Storage อย่างไร?"
